# 工事黒板カメラ（iPhone用・Mac不要／Apple Developer Program不要）

デジタル工事黒板を写し込んで撮影できるiPhoneアプリです。
App Storeを通さず、Safariの「ホーム画面に追加」でインストールする方式（PWA）なので、**MacもApple Developer Program（年会費）も要りません。**
一度インストールすれば**電波のない現場でも動きます**。

---

## 1. できること

| 機能 | 内容 |
|---|---|
| 黒板つき撮影 | 画面に黒板を表示したまま撮影し、写真に焼き込んで保存 |
| 写真の比率 | 常に 4:3（横）／3:4（縦）。カメラ映像の中央を切り出し、画面にも同じ範囲を表示 |
| 黒板の大きさ・位置 | 黒板は写真の幅・高さの1/3（4:3）で固定。位置は「左下（見本どおり）」が初期値で、右下・左上・右上・自由（ドラッグ）も選べる |
| 黒板の文字修正 | 黒板をタップ（または「黒板編集」）で入力。各項目に**最近使った文字のボタン**が出るので1タップで入力 |
| 番号送り | カメラ画面の「＋」「−」で測点などの番号を変更（No.12→No.13、001→002 の桁数も維持） |
| 自動+1 | ONにすると撮影ごとに番号が自動で+1 |
| 連写 | ONにするとシャッター長押しの間、0.5〜3秒ごとに撮影し続ける |
| 連続撮影 | 保存処理は裏で行うので、シャッターを続けて押せる |
| テンプレート | よく使う黒板を保存し、カメラ画面上部のボタン1つで切り替え |
| 項目のカスタマイズ | 行の項目名の変更・追加（最大6行）・削除・並べ替え・表示切替 |
| 撮影日 | 撮影時刻から右下に自動記入（西暦/和暦） |
| 一覧・検索 | 日付ごとに表示、黒板の文字で検索（例：「舗装 No.5」） |
| 書き出し | ZIP（写真＋**写真台帳CSV**）、画像のまま共有、暗号化バックアップ |
| 写真のメタデータ | EXIFに撮影日時、XMPに黒板の全項目を記録 |
| 改ざんチェック | 撮影時に記録した指紋（SHA-256）と書き出し後の写真を照合 |
| リモコン撮影 | Enterキー／スペースキーを送るBluetoothシャッターで撮影可 |

### 黒板のデザイン
見本の黒板（緑地・白枠）と同じ寸法で描いています。

```
┌─────┬────────────────┐
│工事名│マンション改修工事      │
├─────┼────────────────┤
│工事場所│                │
├─────┼────────────────┤
│ 要素 │B-000-UVWXYZ        │
├─────┴────────────────┤
│（備考を入れるとここに表示）         │
│                      │
│○×設備工業株式会社    2026/10/07│
└──────────────────────┘
```
- 上の3行：項目名と内容（項目名は「項目を編集」で変更・追加可）
- 下の広い欄：備考（入力したときだけ表示）
- 左下：会社名　右下：撮影日（自動）
- 長い文字は枠からはみ出さないよう自動で小さくなります
- 横向きの写真では写真の幅・高さの1/3。縦向きの写真でも黒板の高さは写真の短い辺の1/3（横向きと同じ大きさ）です

## 2. セキュリティ

- **写真・黒板・テンプレートはすべて端末内で暗号化して保存**（AES-256-GCM）。暗号鍵はパスコードから PBKDF2-SHA256（60万回）で作った鍵で保護しています。
- **外部への通信は一切しません。** アプリ自体に「自分のサイト以外とは通信禁止」（Content Security Policy）を設定済みです。サーバーやクラウドに写真が送られることはありません。
- 写真は**iPhoneの「写真」Appには保存されません**（iCloud写真への自動アップロードを防ぐため）。
- **自動ロック**：操作しないまま一定時間（初期値1分）、またはアプリを離れたらロック。App切替画面のサムネイルにも写真を映しません。
- **パスコード総当たり対策**：5回以上間違えると待ち時間が延びます。設定で「10回/20回間違えたら全データ消去」も選べます。
- 暗号化データには「どの写真のどの部分か」を結び付けているため、データの差し替えも検出します。
- 写真の削除は完全削除です。

### 必ず守ってほしいこと
1. **アプリのパスコードは英数字を混ぜて8文字以上**に。数字6桁だけだと、端末を解析された場合に破られやすくなります。
2. **iPhone本体にもパスコード（Face ID）を設定**してください（端末自体の暗号化が有効になります）。
3. **パスコードを忘れると写真は二度と取り出せません**（そういう仕組みです）。
4. **iPhoneの「設定 → Safari → 履歴とWebサイトデータを消去」を実行すると、このアプリの写真も消えます。** 定期的に「書き出し」または「暗号化バックアップ」をしてください。
5. 書き出したZIPや画像は暗号化の外に出ます。送り先・保存先に注意してください。暗号化のまま保管・移行したいときは「暗号化バックアップ（.kbk）」を使ってください。

## 3. 公共工事での利用について（重要）

国土交通省などの公共工事で「デジタル工事写真の小黒板情報電子化（電子小黒板）」として使う場合は、**施工管理ソフトウェア産業協会（J-COMSIA）の信憑性確認（改ざん検知機能）検定に合格したソフト**が求められます。
このアプリは独自にSHA-256で改ざん検知をしていますが、**J-COMSIAの検定は受けていません。**
公共工事で使う場合は、事前に監督職員（発注者）へ使用可否を確認してください。民間工事・社内記録・自社の品質管理用にはそのまま使えます。

## 4. インストール手順（iPhoneだけでできます・約15分）

アプリのファイルを「https で見られる場所」に置き、iPhoneのSafariで開いてホーム画面に追加します。
ここでは無料の **GitHub Pages** を使います。
（置くのはアプリのプログラムだけです。**写真は一切アップロードされません**。プログラムは公開されますが、写真は各iPhoneの中だけにあるので問題ありません。）

### 4-1. ファイルを用意
1. 受け取った `kokuban-camera.zip` を iPhone の「ファイル」Appに保存し、タップして展開します。
2. 中に `index.html` `app.js` など**14個のファイル**があることを確認します（フォルダの中にフォルダはありません）。

### 4-2. GitHubに置く
1. Safariで https://github.com を開き、アカウントを作成（またはログイン）。
2. 右上の「＋」→「New repository」。
   - Repository name：`kokuban-camera`（好きな英数字でOK）
   - **Public** を選ぶ（無料のPagesはPublicが必要。中身はプログラムだけです）
   - 「Create repository」
3. 作成後の画面で「uploading an existing file」をタップ → 「choose your files」→ 4-1で展開した**14個のファイルをすべて選択** → 下の「Commit changes」。
4. リポジトリの「Settings」→ 左メニュー「Pages」
   - Source：「Deploy from a branch」
   - Branch：「main」「/(root)」→「Save」
5. 1〜2分待つと、同じ画面の上部に `https://（あなたのID）.github.io/kokuban-camera/` と表示されます。これがアプリのアドレスです。

### 4-3. iPhoneにインストール
1. **Safari**で上のアドレスを開きます（ChromeなどではなくSafari）。
2. 画面下の共有ボタン（□に↑）→「**ホーム画面に追加**」→「追加」。
3. ホーム画面の「黒板カメラ」アイコンから起動します。**以後は必ずこのアイコンから起動してください。**
4. パスコードを決めて「はじめる」。
5. カメラの許可を求められたら「許可」。
   - 出ない／拒否してしまった場合：「設定」App → アプリ → Safari → カメラ →「許可」。

> 一度起動すれば、以後は電波がなくても動きます。

## 5. 使い方（1日100枚以上撮る場合のおすすめ）

1. **朝いちばんに**「黒板編集」で工事名・工事場所・会社名などを入力し、「今の内容をテンプレート保存」。
   現場や部位ごとにテンプレートを作っておくと、カメラ画面上部のボタンで瞬時に切り替えられます。
2. カメラ画面の「＋−」で変える項目は初期値「要素」。設定で別の行に変えられます。
3. 番号を順番に撮るなら「**自動+1 ON**」→ シャッターを押すたびに B-000 → B-001 → B-002 … と進みます（桁数はそのまま）。
4. 同じ黒板で何枚も撮るなら「**連写 ON**」→ シャッター長押しで連続撮影。
5. 黒板の文字を直すときは**黒板をタップ**。各項目の下の「最近使った文字」ボタンで入力の手間を減らせます。
6. 一日の終わりに 一覧 →「選択」→「全選択」→「書き出し」→「ZIPにまとめる」。
   ZIPには写真と `写真台帳.csv`（ファイル名・撮影日時・黒板の全項目・指紋）が入ります。100枚ごとに分割されます。
7. 書き出しが済んだ写真は削除すると、iPhoneの容量を節約できます。

### 保存サイズの目安
| 設定 | 1枚 | 100枚 |
|---|---|---|
| 1280×960 | 約0.3MB | 約30MB |
| 1600×1200（初期値） | 約0.5MB | 約50MB |
| 1800×1350（見本と同じ） | 約0.6MB | 約60MB |
| 2048×1536 | 約0.8MB | 約80MB |

## 6. 改ざんチェック
設定 →「改ざんチェック」→ 書き出したJPEGを選ぶと、撮影時の指紋と照合して「✓一致」「✗不一致・未登録」を表示します。
写真台帳CSVにも各写真の指紋（SHA-256）が入っているので、第三者もパソコンで照合できます
（Windowsなら PowerShell で `Get-FileHash ファイル名.jpg` を実行し、CSVの値と比べます）。

## 7. 機種変更・バックアップ
- 設定 →「全写真を暗号化バックアップ」→ `.kbk` ファイルを「ファイル」Appや社内PCに保存。
- 新しいiPhoneでアプリをインストール → 設定 →「暗号化バックアップから復元」。
- 復元時にも指紋を照合し、壊れた・改ざんされた写真は取り込みません。

## 8. アプリの更新
GitHubのリポジトリで変更したファイルを上書きアップロード → iPhoneでアプリを**2回起動し直す**と新しい版になります。
写真データはそのまま残ります。

## 9. 困ったとき
| 症状 | 対処 |
|---|---|
| 黒板が動かせない | 「黒板編集」→「黒板の位置」を「自由」にする（初期値は見本どおり左下に固定） |
| カメラが真っ黒 | 一度ロック（🔒）して開き直す。直らなければアプリを上にスワイプして終了→再起動 |
| 毎回カメラ許可を聞かれる | iOSの仕様です。「設定」→アプリ→Safari→カメラ→「許可」にすると減ります |
| 「空き容量が不足」 | 書き出して削除する／設定で画像サイズを小さくする |
| パスコードを忘れた | 写真は取り出せません。ロック画面の「パスコードを忘れた場合」から全データを消去して最初からやり直せます |

## 技術情報（社内のIT担当者向け）
- 構成：HTML/CSS/JavaScript（外部ライブラリ・外部CDNなし）、Service Workerでオフライン化
- 保存：IndexedDB。`photos`（暗号化メタ）/`thumbs`/`images` を分離。すべて AES-256-GCM、AAD に `写真ID:種別` を付与
- 鍵：ランダムなデータ鍵(DEK)を PBKDF2-SHA256（600,000回, salt 16B）で作った鍵で包んで保存。パスコード変更はDEKの包み直しのみ
- 画像：JPEG 4:3（映像中央を切り出してcanvasで合成）。黒板は写真の短辺の1/3の高さ・4:3、寸法は見本（600×450）からの実測値を割合で保持（board.js）、EXIF（DateTimeOriginal ほか）、XMP（`dc:description` と `kb:Board` に黒板項目）
- 改ざん検知：最終JPEGのSHA-256を暗号化メタに記録
- バックアップ：`KBK1 | salt | iv | AES-GCM(無圧縮ZIP)`、パスワードはPBKDF2で鍵化
- 通信：CSP `default-src 'self'`、`connect-src 'self'`。外部送信なし
- ファイル：`index.html` `styles.css` `app.js` `crypto.js` `db.js` `board.js` `jpegmeta.js` `zip.js` `sw.js` `manifest.webmanifest` `icon-180.png` `icon-192.png` `icon-512.png` `README.md`
